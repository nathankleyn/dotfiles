# Zed Extensions

There's no way to currently install extensions programmatically for Zed, so here's a list of extensions to install after setting up Zed manually:

- Catppuccin
- Dockerfile
- EJS
- Git Firefly
- HTML
- Kotlin
- Liquid
- LOG
- Oxc
- Solarized
- SQL
- Terraform
- TOML
- Vue
- Warm Burnout
